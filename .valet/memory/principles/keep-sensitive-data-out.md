# Keep sensitive data out of shared places

Treat shared places as readable by everyone with access. Do not write sensitive data into them: compensation, personal contact details, health or HR matters, customer secrets, or credentials. Link to the system that holds it.

Reason: shared text is copied and cached. It cannot be made private again.

Example: write "salary bands are in the HR system", not the bands.

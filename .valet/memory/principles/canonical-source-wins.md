# The canonical source wins

Find the source that owns the fact: the system of record, the spec, or the document its owner keeps current. Use it, and say which you used. Do not average two sources or guess between them.

Reason: a guess between two sources spreads the error to every reader.

Example: a wiki page and the deploy config give different ports. Use the config, and flag the stale page.
